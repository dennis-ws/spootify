# Spootify
A self-hosted music streaming frontend built with React Expo. Developed as a personal project to strengthen my React and Javascript skills while exploring mobile application development. Would I suggest you to use this? No, but feel free to take a look at the code.

# Features
* Music streaming interface
* Mobile application built with Expo
* Self-hosted frontend

# Pre-requisite
Before running Spootify, make sure you have:
* Node.js installed
* Expo Go installed on your mobile device

# Usage
Prior to starting the server, first install the dependencies
```
npm install
```
Then you can start the development server
```
npx expo start -c
```
Run the application by
* Opening Expo Go on your mobile device
* Scan the QR code displayed in your terminal
* **MAKE SURE YOUR COMPUTER AND MOBILE DEVICE ARE CONNECTED TO THE SAME NETWORK**
